# О проекте

Простой веб-клиент для общения в режиме реального времени на React + TypeScript.

## Технологии

- Frontend: React, TypeScript, SCSS
- Инструменты: npm, Create React App
- Реальное время: Socket.IO для обмена сообщениями с сервером

## Установка и запуск

- git clone https://github.com/steel-mountain/chat-client.git
- cd chat-client
- npm install
- npm start

Приложение будет доступно в браузере по адресу: http://localhost:3000

Для работы необходим запущенный сервер (chat-server).

## Как использовать

1. Откройте приложение в браузере.
2. Введите:

- Название комнаты
- Ваше имя

3. Вы попадёте в выбранную комнату, где сможете общаться с другими пользователями в реальном времени.
   **Важно:** Чтобы общаться с другими, им нужно знать название вашей комнаты.
